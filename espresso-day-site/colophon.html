Как сделан этот сайт

Инструменты

Разметка сайта выполнена вручную без применения сторонних инструментов и фреймворков. Текущая версия проекта не содержит CSS и JavaScript в соответствии с требованиями задания. Данный подход направлен на формирование корректной семантической структуры документа. Отсутствие визуального оформления позволяет на раннем этапе верифицировать код и исключить использование нецелевых тегов. Например, список ссылок в навигации выглядит так: 

<nav>
    <ul>
        <li><a href="index.html">Главная</a></li>
    </ul>
</nav>

Файлы открывались прямо в браузере без сервера.

Проверка и валидация

Все страницы проекта прошли проверку валидатором W3C и не содержат ошибок. Использование CSS и JavaScript на данном этапе исключено согласно техническому заданию. В настоящий момент основной акцент сделан на создании чистой и семантически корректной разметки.
